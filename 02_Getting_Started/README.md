# Lesson 2: Getting Started

This section is where Dart stops being a concept and starts becoming something you can actually use.

The goal of this lesson is not only to write your first programs, but to build good habits from the beginning:

- run code often
- keep examples small
- read errors carefully
- structure files clearly
- write code that is easy to grow later

These are beginner-friendly habits, but they are also senior developer habits.

## What You Should Learn Here

By the end of this section, you should be able to:

- write and run a basic Dart file
- understand where execution begins
- use DartPad for quick experimentation
- write useful comments without cluttering code
- organize a small Dart program in a readable way

## Senior Developer Mindset For This Section

Try to build these habits immediately:

- change one thing at a time, then run the code
- do not guess what the program does, verify it
- keep `main()` easy to read
- use clear names instead of clever names
- let the tools help you with formatting and analysis

## Suggested Workflow

For every example in this lesson:

1. type the code yourself
2. run it
3. change something small
4. predict the new output
5. run it again

That loop is how strong developers learn quickly.
