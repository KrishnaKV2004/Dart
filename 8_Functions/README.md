## Why This Lesson Matters

Real programs are not built from one giant `main()` function.
They are built from many small units of logic that each do one job well.

Functions help you:

- organize code
- reuse logic
- reduce duplication
- improve readability
- prepare for testing

## Senior Developer Mindset For Functions

Strong developers usually prefer functions that are:

- small
- well named
- focused on one responsibility
- easy to call correctly
- easy to change later

If a function becomes hard to explain, it is often too large or doing too many things.

## What You Should Learn Here

By the end of this section, you should be able to:

- define and call functions
- pass data into functions
- return results from functions
- choose good parameter styles
- understand anonymous and higher-order function basics

## Flutter Connection

Functions are everywhere in Flutter:

- event handlers
- helper methods
- validation logic
- data transformers
- reusable business rules

If you learn functions well in Dart, you will write much cleaner Flutter code later.
