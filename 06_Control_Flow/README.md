# Lesson 6: Control Flow

This section teaches how a Dart program makes decisions.

Until now, our programs have mostly followed a straight path:

1. store some values
2. do some work
3. print the result

Control flow changes that.
Now the program can choose different paths depending on conditions.

2. [if else](./if%20else/README.md)
3. [else if](./else%20if/README.md)

## Why This Lesson Matters

Real applications are full of decisions:

- Is the user logged in?
- Is the cart empty?
- Is the form valid?
- What message should be shown?
- Which screen should open next?

Without control flow, apps cannot react intelligently.

## Senior Developer Mindset For Control Flow

Strong developers write conditions so they read like business rules.

They try to make logic:

- clear
- predictable
- easy to change
- easy to test

If a condition gets hard to read, they simplify it with:

- better variable names
- smaller helper functions
- flatter branching

## What You Should Learn Here

By the end of this section, you should be able to:

- make decisions with `if`
- choose between two paths with `if else`
- handle multiple conditions with `else if`
- select cases using `switch`
- understand basic modern Dart control flow using switch expressions and pattern matching

## Flutter Connection

Control flow is everywhere in Flutter:

- show loading or content
- display an error or success state
- check permissions
- render different widgets based on data

Clean decision logic in Dart becomes clean UI logic in Flutter.
