# Lesson 5: Input Output

This section teaches how Dart programs communicate with users.

Up to now, most examples have used fixed values inside the code.
Input and output change that.
Now the program can:

- show messages
- ask for data
- react to what the user enters

## Topics In This Lesson

1. [Printing Output](./Printing%20Output/README.md)
2. [Reading Input](./Reading%20Input/README.md)
3. [String Interpolation](./String%20Interpolation/README.md)
4. [Formatting Output](./Formatting%20Output/README.md)

## Why This Lesson Matters

Input and output are the start of interaction.

Without output:

- users cannot see results
- developers cannot inspect program behavior

Without input:

- programs stay static
- users cannot provide data

## Senior Developer Mindset For This Section

Strong developers care about more than "it works."
They also care about:

- clear prompts
- predictable output
- safe input handling
- helpful fallback behavior

That mindset is valuable in both console apps and Flutter apps.

## What You Should Learn Here

By the end of this section, you should be able to:

- print useful output
- read user input from the console
- build readable messages with interpolation
- format output so it is easy to understand

## Flutter Connection

Flutter apps do not use console input in the same way, but the thinking transfers directly:

- prompts become labels and hints
- output becomes UI text
- input handling becomes form handling
- formatting becomes user-friendly display

So this lesson is more important than it may first appear.
